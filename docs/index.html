Karate API Testing

QA Testing Project

Project Overview

A comprehensive API testing suite built with Karate framework, demonstrating automated REST API testing against the JSONPlaceholder API. Covers positive and negative test scenarios, response schema validation, and data-driven testing using BDD-style syntax.

Tech Stack

Java Karate JUnit 5 JSONPlaceholder API BDD REST API

Key Features

  • BDD-style API tests with Karate's Gherkin syntax
  • Negative testing for invalid inputs and edge cases
  • JSON Schema validation for response structures
  • CRUD operation testing (GET, POST, PUT, DELETE)
  • Reusable Karate features and call variables
  • Integrated with JUnit 5 runner and Maven
